Open source React component

React Table

A fast, accessible data table for React. Sorting, filtering, grouping, editing, paging and virtual scrolling work out of the box, and you take full control of the state when you need it.

Quick start

Your first table in a minute

Install the package, import the styles and pass the columns and the data. Sorting, filtering, editing and paging are one prop each.

npm install ka-table
